# Аудит Athena 0.1.5 — 14 октября 2026

## Объём и причины

Проверены два дефекта иконки, сообщённых пользователем:

1. Тёмный квадрат: исходный PNG не содержал alpha; четыре внешних угла были
   полностью непрозрачными. Новый XCTest воспроизвёл ошибку на старом ресурсе.
2. Заглушка Finder: проблема подтверждена в открытом окне Finder, хотя
   NSWorkspace возвращал правильную иконку. В plist стоял CFBundleIconName
   без Asset Catalog. Также Finder мог наблюдать недособранное приложение
   при удалении и повторном создании bundle на месте.

## Исправления

- После согласия пользователя применена локальная геометрическая alpha-маска
  по округлой рамке, без генерации нового рисунка. Сценарий
  `script/prepare_athena_icon.swift` документирует границу и сглаживание;
  он не запускается при обычной сборке.
- Из PNG пересобраны все размеры ICNS, resource bundle и установщик.
- Убран CFBundleIconName; оставлен CFBundleIconFile со ссылкой на ICNS.
  Это соответствует [описанию ключей Apple](https://developer.apple.com/library/archive/documentation/General/Reference/InfoPlistKeyReference/Articles/CoreFoundationKeys.html).
- Bundle готовится во временном каталоге и проверяется до замены в dist.
  При ошибке перемещения восстанавливается предыдущая сборка. Finder больше
  не видит приложение в промежуточном недособранном состоянии.
- Bundle ID, Keychain, MCP ID и пользовательские настройки не изменялись.

## Свежие проверки

- 45 XCTest: 0 ошибок; новый тест проверяет наличие alpha, четыре прозрачных
  угла, квадратный размер и непрозрачный центр изображения.
- `swift build`, release-сборка и упаковка PKG: успешно.
- `script/verify_app_bundle.swift` проверяет имя, исполняемый файл, отсутствие
  ошибочной ссылки на Asset Catalog и прозрачные углы всех растров ICNS.
- Упаковка и эта проверка добавлены в GitHub CI.
- **Живой Finder:** после замены готового bundle Афина отображается в папке
  dist вместо стандартной заглушки; внешний тёмный квадрат отсутствует.
- PKG распакован, bundle проверен через `codesign --verify --deep --strict`
  и сценарий проверки ICNS.
- Ссылки, публичное имя, diff и типовые секреты проверены перед коммитом.

## Вердикт и ограничения

Исправления ресурса, метаданных, упаковки и отображения в Finder проверены.
Полный повторный аудит всех подсистем не проводился: выполнен аудит изменения
и существующий набор регрессионных тестов. Живой Dock после установки новым
пользователем не проверялся; старый экземпляр Athena нужно завершить и открыть
обновлённый.

Пакет arm64, без Apple Developer ID и notarization. Среда упаковки создаёт
AppleDouble-записи; перед подписанным распространением нужен тест на чистом Mac.
Реальные облачные API и Intel Mac в этой проверке не использовались.

Контрольная сумма установщика — в [SHA256SUMS.txt](../installers/SHA256SUMS.txt).
