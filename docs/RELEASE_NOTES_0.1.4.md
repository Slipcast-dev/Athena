# Athena 0.1.4 — единое публичное имя

- Оформление проекта, документация, лицензия и диагностический отчёт используют
  только публичное имя Athena.
- Названия и описания архивных релизов обновлены; содержимое архивных пакетов
  и их контрольные суммы сохранены.
- В CI добавлена проверка публичного имени. Технические ID сохранены для
  совместимости ключей, истории и MCP-подключений.
- 44 XCTest, debug/release-сборки и аудит пройдены.

[Аудит версии](https://github.com/Slipcast-dev/Athena/blob/main/docs/AUDIT_0.1.4.md).

Установщик `Athena-0.1.4-unsigned.pkg`: macOS 14+, Apple Silicon (arm64).
**Без подписи Apple Developer ID и notarization Apple.** Gatekeeper может
блокировать установку. Это предварительная сборка для технического тестирования.

SHA-256: `c4fc6c4fa38577ac3224836325b3f606d0df643be27ee5f5e2030b51e4038e25`.
Файл SHA256SUMS.txt приложен к релизу. AppleDouble-записи среды упаковки остаются
известным ограничением; реальные облачные API и интерактивный UI-тест не проверялись.
