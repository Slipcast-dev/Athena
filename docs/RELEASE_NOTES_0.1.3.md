# Athena 0.1.3 — исправления аудита и новое имя

Предварительный выпуск для macOS 14+ / Apple Silicon, опубликованный в
[Slipcast-dev/Athena](https://github.com/Slipcast-dev/Athena).

- Приложение переименовано в Athena; история, ключи и внутренние ID сохранены.
- Иконка Афины явно задана в bundle и Dock; локальная сборка обновляет свою
  запись LaunchServices для корректного значка Finder.
- Кнопки подключения провайдера удалены из чата. Подключение — только в
  разделе «ИИ-провайдеры».
- Исправлены HTTPS-проверка streaming, обработка обрыва/повреждения SSE и
  обновление Keychain без удаления предыдущего значения.
- 44 XCTest, debug/release-сборки и повторный аудит выполнены.

Установщик: `Athena-0.1.3-unsigned.pkg`, macOS 14+, Apple Silicon (arm64).
**Нет подписи Apple Developer ID и notarization.** Gatekeeper может блокировать
установку. Сборка предназначена для технического тестирования.

[Повторный аудит](https://github.com/Slipcast-dev/Athena/blob/main/docs/AUDIT_0.1.3.md)
закрывает три замечания предыдущей версии. Выполнены очистка старых артефактов
и проверка ссылок. SHA-256 опубликован в файле `SHA256SUMS.txt` рядом с установщиком.
SHA-256: `fea342da3ff494d1ae8a04d7847a0de9bf9a8fa8729d2a56046ef951c24e3787`.
После установки под новым именем переподключите MCP, если клиент сохранил
абсолютный путь к старому MacAssistant.app.
