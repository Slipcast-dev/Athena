# Аудит Athena 0.1.4 — 14 октября 2026

## Согласованный объём

Публичное имя приложения — Athena. Обновлены оформление GitHub, README,
документация, лицензия, комментарии, названия и описания архивных релизов,
имена файлов архивных установщиков и заголовок диагностического отчёта.

SwiftPM-модули, bundle ID, Keychain service, идентификаторы MCP и исторические
коммиты сохранены по выбранному пользователем варианту совместимости.
Технические идентификаторы в исходниках и инструкциях не являются названием
приложения. История, ключи и подключённые клиенты не мигрируются и не очищаются.

## Проверки

- 44 XCTest проходят; проверка обезличенного отчёта дополнена утверждением,
  что его заголовок содержит имя Athena.
- Debug/release-сборки и PKG 0.1.4 собраны.
- Распакованный bundle проверяется `codesign --verify --deep --strict`;
  сверяются версия, ICNS, MCP и обновлённая лицензия.
- `script/check_branding.py` проверяет публичную форму имени во всех текстовых
  файлах Git, включая конфигурацию среды разработки. Проверка включена в CI.
- `script/check_links.py` проверяет локальные ссылки и якоря; внешний режим
  запускается после публикации релиза.
- Diff и типовые секреты проверены. Пользовательские данные не менялись.
- Архивные установщики переименованы через метаданные GitHub: их содержимое
  и SHA-256 не изменялись; соответствующие файлы контрольных сумм обновлены.

## Результат и ограничения

Прежнее публичное название отсутствует в проверенных текущих текстах и
оформлении релизов. Совместимость технических ID сохранена сознательно.
Новых блокирующих дефектов в этом изменении не найдено.

не проводились. PKG arm64, без Apple Developer ID и notarization. В payload
остаются служебные AppleDouble-записи среды упаковки.
