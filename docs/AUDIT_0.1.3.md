кнопки подключения из чата и переименовать приложение. База: `97cb535`.

## Закрытые замечания

| Пункт | Изменение | Доказательство |
| --- | --- | --- |
| A-01 HTTPS streaming | AIEndpointValidator вызывается до чтения ключа | HTTP-профиль даёт insecureEndpoint, а не missingAPIKey; сеть не используется |
| A-02 SSE EOF/JSON | OpenAIStreamDecoder требует DONE либо finish_reason, ошибки JSON не подавляются | Тесты обрыва после частичного текста, повреждённых данных, role/usage и двух вариантов завершения |
| A-03 Keychain | SecItemUpdate; SecItemAdd только при errSecItemNotFound | Тесты сохранности старого значения при ошибке, обновления, создания и ошибки создания |
| Иконка | Athena.icns в CFBundleIconFile; тот же образ для Dock; локальная перерегистрация LaunchServices | NSWorkspace.icon(forFile:) возвращает образ Афины без наложения знака запрета после регистрации |
| Чат | Удалены кнопки подключения и настройки, оставлена текстовая подсказка | Проверка исходников и отрисованные макеты обеих тем |
| Имя | Athena.app, окно/боковая панель/чат и пользовательские строки Athena | Метаданные готового bundle и макеты UI |

Старый ключ не удаляется кодом save; тесты не изменяют настоящий пользовательский
Keychain. При ошибке потока ViewModel сохраняет переписку и контекст повтора —
это дополнительно покрыто существующими тестами отмены и восстановления.

## Иконка и запуск

Исходный ICNS был корректен и присутствовал в старом bundle. Точная причина
пустого значка на исходном скриншоте ретроспективно не доказана. На новой сборке
воспроизведён знак запрета поверх правильной иконки до обновления записи
LaunchServices; после `lsregister -f` он исчез. Обновление только записи Athena
добавлено в сценарий сборки. Общий кэш Finder не очищался.

`script/verify_app_bundle.swift` проверяет имя, bundle ID, ICNS и исполняемый
файл, затем сохраняет иконку, полученную через системный NSWorkspace.
Приложение из `dist/Athena.app` запущено; процесс подтверждён.

## Совместимость и ограничения

Bundle ID `com.macassistant.app`, служба Keychain, SwiftPM-модули и MCP ID
`mac-assistant` сохранены. Репозиторий не переименовывался. Если внешний клиент
сохранил абсолютный путь к `MacAssistant.app`, после установки Athena нужно
отключить и подключить MCP заново в «Агентах», затем перезапустить клиент.

Полный интерактивный UI-тест, реальные облачные API и сбой настоящего Keychain
не выполнялись. Тесты проверяют логику на системных границах и отрисовку.
Установщик arm64, без Developer ID и notarization; служебные AppleDouble-записи
среды упаковки остаются известным ограничением. Это локальный тестовый выпуск.

Все три замечания A-01/A-02/A-03 закрыты на уровне исходников и регрессионных
тестов. Новых блокирующих дефектов в изменённом поведении не обнаружено;
это не утверждение об отсутствии любых дефектов во всём проекте.
