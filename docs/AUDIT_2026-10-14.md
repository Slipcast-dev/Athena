# Аудит Mac Assistant 0.1.1 — 14 октября 2026

Проверены четыре запрошенных исправления, их вызовы из SwiftUI, хранение данных,
обработка ошибок и релизный пакет. Аудит выполнен по исходникам и исполняемым
тестам; независимый внешний аудит и проверка реальных облачных API не проводились.

## Соответствие требованиям

| Требование | Проверка | Результат |
| --- | --- | --- |
| История нескольких диалогов | Повторное создание store, восстановление последнего диалога, обновление по ID, создание третьего | Пройдено |
| Старые данные | JSON без нового поля retryMessages | Пройдено |
| Повреждённая история | Ошибка upsert без изменения исходного JSON | Пройдено |
| Потоковый ответ | Управляемый поток, наблюдение частичного текста до завершения и индикатор по ID | Пройдено на уровне ViewModel; визуальная проверка недоступна |
| Ошибка и повтор | Сохранение частичного ответа, повтор после восстановления без второго вопроса | Пройдено |
| Отмена | Запрос сохраняется, генерация прекращается, повтор доступен | Пройдено |
| Harness | Block/flow YAML, quoted ID, соседние записи внутри insert, похожий ID, повтор connect/disconnect | Пройдено |
| Некорректный Harness | Синтаксическая ошибка, несколько документов, неверная форма insert, повторяющиеся ключи | Запись остановлена, исходник сохранён |
| Получатель отчёта | Выбор профиля и API, сброс согласия при смене ID/адреса, отказ без согласия | Пройдено |

## Исправления по результатам проверки

- Запрос сохраняется до обращения к сети; actor делает обновление по ID одним
  действием, без перезаписи других диалогов.
- Контекст повтора хранится вместе с диалогом и читается из старого JSON как
  optional, сохраняя совместимость.
- Ошибки итератора Yams проверяются явно; неоднозначные повторяющиеся ключи
  отклоняются до изменения пользовательского файла.
- Получатель и модель захватываются перед асинхронной отправкой; повторная
  отправка заблокирована до завершения, согласие сбрасывается после отправки.
- Сторонние лицензионные уведомления включены и в репозиторий, и в bundle.

## Проверки выпуска

- `swift test`: 35 XCTest, без ошибок.
- `swift build`: debug-сборка успешна.
- `./script/build_and_run.sh --installer`: release-сборка и создание PKG успешны.
- `Info.plist`: версия 0.1.1, минимальная macOS 14.0; бинарник arm64.
- `codesign --verify --deep --strict`: проверяются bundle и приложение из payload.
- Проверены наличие MCP, ресурсов SwiftPM, LICENSE и THIRD_PARTY_NOTICES.
- `git diff --check` и поиск типовых секретов: замечаний не найдено.

## Ограничения

- PKG unsigned, Apple Developer ID, hardened runtime и notarization отсутствуют.
- В payload есть служебные AppleDouble-записи текущей среды macOS.
- Процесс приложения запущен; визуальная проверка окон не выполнена из-за ошибки
  подключения средства управления интерфейсом (`native pipe closed`).
- Реальные запросы к облачным провайдерам и запуск внешнего Harness не проверялись:
  тесты используют управляемые сетевые границы и временные конфигурации.
- Yams сохраняет значения и типы соседних YAML-узлов, но нормализует форматирование
  и не сохраняет комментарии при изменении файла.

Блокирующих дефектов в проверенном поведении после исправлений не обнаружено.
Полная готовность публичного подписанного выпуска остаётся неподтверждённой.
