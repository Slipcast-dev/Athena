## CP-08-DEEPSEEK-HARNESS

- **Дата:** 13 октября 2026
- **Статус:** завершён
- **Содержание:** на основе официальной документации DeepSeek Harness создан
  отдельный локальный MCP-процесс `MacAssistantMCP` с транспортом `stdio`.
  Реализованы `initialize`, `tools/list` и `tools/call`, а `LocalAgentBridge`
  исполняет строго четыре операции только для чтения.
- **Безопасность:** нет запуска shell, AppleScript, передачи пользовательских
  путей, ключей, произвольных аргументов или сетевых запросов. Неизвестные
  инструменты возвращают контролируемый отказ; сервер не открывает порт.
- **Проверки:** `swift test` — 22 теста пройдены; `swift build` — успешно;
  вручную проверены JSON-RPC ответы на `initialize`, `tools/list` и отказ
  `shell.execute`.
- **Ограничения:** мост не регистрируется автоматически в Harness и пока не
  поддерживает управляемые действия. Они потребуют отдельной модели согласия и
  аудита.
- **Коммит:** `feat(agent): add DeepSeek Harness MCP bridge`.
