## CP-03-DIAGNOSTICS

- **Дата:** 13 октября 2026
- **Статус:** завершён
- **Содержание:** добавлены локальные сервисы системной информации и диагностики, расчёт CPU по последовательным Mach-снимкам, показатели памяти и накопителя, дашборд и экран диагностического отчёта.
- **Пороги:** накопитель — предупреждение с 80 %, критический уровень с 90 %; CPU — предупреждение с 80 %, критический уровень с 95 %. Высокое использование RAM без подтверждённого pressure не считается неисправностью.
- **Проверки:** `swift test` — 10 тестов пройдены; `swift build` — успешно; локальный запуск приложения был проверен в ходе блока.
- **Ограничения:** memory pressure намеренно не классифицируется без надёжного источника.
- **Коммит:** `feat(diagnostics): add local system monitoring`.
- **Тег:** `CP-03-DIAGNOSTICS`.

## CP-05-AI-PROVIDERS

- **Дата:** 13 октября 2026
- **Статус:** завершён
