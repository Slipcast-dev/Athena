# Athena 0.1.1 — архивный выпуск

Предварительная сборка для **macOS 14+ / Apple Silicon (arm64)**.
Установщик **не подписан Apple Developer ID** и **не нотарифицирован Apple**.
Gatekeeper может предупредить или заблокировать установку.

## Изменения

- Чат восстанавливает сохранённые диалоги и обновляет текущий по ID, сохраняя
  остальные. Добавлены выбор диалога и создание нового.
- Сообщения видны во время генерации, индикатор расположен рядом с ответом.
  Ошибка и отмена сохраняют переписку; запрос можно повторить после перезапуска.
- Harness YAML разбирается структурно: удаляется только собственная запись
  Athena, соседние записи сохраняются. Некорректный YAML не меняется.
- Перед отправкой диагностического отчёта можно выбрать провайдера и увидеть
  API-адрес. Смена получателя сбрасывает согласие.

## Проверка

35 XCTest проходят успешно; debug/release-сборки и целостность распакованного
приложения проверены. Подробности и границы проверки:
[аудит](https://github.com/Slipcast-dev/Athena/blob/main/docs/AUDIT_2026-10-14.md).
Визуальная проверка интерфейса и запросы к реальным облачным API не выполнены.

Файл: `Athena-0.1.1-unsigned.pkg`.
SHA-256: `a4e8021f1b485ee1d6610d09674295b47115bedef5546063007b1c425f9c6de2`.
Архивный установщик доступен в соответствующем GitHub Release.

В payload присутствуют служебные AppleDouble-записи `._*` этой среды macOS.
При изменении YAML форматирование нормализуется, комментарии не сохраняются.
Для подписанного выпуска нужна отдельная проверка на чистом Mac и сертификаты
Developer ID Application / Developer ID Installer, а также notarization.
