# Athena 0.1.5 — прозрачная иконка

Удалён тёмный квадрат вокруг иконки: область за округлой рамкой теперь
прозрачная. Сам рисунок Афины сохранён без генерации нового изображения.
Обновлены PNG, ICNS, приложение и установщик.

Исправлена стандартная заглушка вместо иконки в Finder: убрана ссылка на
несуществующий Asset Catalog. Сборка публикует уже готовый и проверенный
bundle, а не создаёт его по частям в открытой папке dist. Отображение Афины
подтверждено в живом Finder.

Добавлен регрессионный тест прозрачности. Упаковка и GitHub CI дополнительно
проверяют внешние углы всех декодированных размеров ICNS.
45 XCTest проходят; debug/release-сборки проверены.

Скачайте `Athena-0.1.5-unsigned.pkg` и сверьте SHA-256 из `SHA256SUMS.txt`.
После установки завершите старый экземпляр Athena и запустите новый.

macOS 14+, только Apple Silicon (arm64). Это предварительный выпуск:
установщик **без Apple Developer ID и notarization Apple**. macOS может
показать предупреждение или заблокировать установку. В среде упаковки
остаются служебные AppleDouble-записи; нужен тест на чистом Mac перед
подписанным публичным выпуском.

Настройки, данные, Keychain и технические идентификаторы не изменялись.
