# DeepSeek Harness: локальный MCP-мост

## Назначение

`MacAssistantMCP` — отдельный исполняемый процесс для подключения DeepSeek
Harness по стандартному вводу-выводу. Выбран `stdio`: официальный клиент Harness
рекомендует этот транспорт для локальной программы. Процесс не открывает порт и
не имеет командной оболочки.

## Разрешённые операции

| MCP-инструмент | Результат | Разрешение |
| --- | --- | --- |
| `system.get_info` | Модель, версия macOS, архитектура и ядра; без серийного номера | Только чтение |
| `system.get_metrics` | CPU, RAM и свободное место | Только чтение |
| `diagnostics.run` | Локальные выводы диагностики | Только чтение |
| `storage.get_overview` | Общий и доступный объём диска | Только чтение |

Мост отклоняет любые другие имена инструментов. Он не принимает пути, команды
shell, AppleScript, API-ключи или текст для отправки в сеть. Сканирование файлов,
изменение настроек, удаление файлов и вызовы ИИ не включены: для них потребуется
отдельный блок с пользовательским согласием и аудитом.

## Сборка и проверка

Из корня проекта:

```zsh
swift build
swift run MacAssistantMCP
```

После установки `.pkg` MCP-исполнитель находится внутри приложения по пути
`/Applications/MacAssistant.app/Contents/MacOS/MacAssistantMCP`. При разработке
вместо него допустима команда
`swift run --package-path /Users/Aleksandr/Documents/Проекты/MacAssistant MacAssistantMCP`.
Параметр `serverName` в конфигурации Harness должен быть `mac-assistant`:
Harness публикует его инструменты под пространством имён `mcp__mac-assistant__…`.

## Подключение из приложения

Основной способ подключения — раздел **Агенты** в Mac Assistant. Нажмите
«Подключить» у Codex или DeepSeek Harness и подтвердите действие. Приложение
создаёт только запись `mac-assistant`; повторное подключение не дублирует её.

Кнопка «Отключить» удаляет только эту запись. Другие MCP-серверы и настройки
клиента не меняются. После подключения или отключения Harness перезапустите его,
чтобы он перечитал локальную конфигурацию.

## Запасное подключение к Codex из терминала

После установки приложения выполните из корня репозитория:

```zsh
./script/configure_mcp.sh --codex
```

Скрипт вызывает официальный `codex mcp add`, регистрирует локальный stdio-сервер
под именем `mac-assistant` и выводит его сохранённую конфигурацию. При этом
изменяется только одноимённая запись; остальные MCP-серверы Codex не затрагиваются.

## Запасная конфигурация DeepSeek Harness из терминала

Сначала выведите и проверьте конфигурацию:

```zsh
./script/configure_mcp.sh --harness-config
```

Вставьте напечатанный блок в используемый доверенный Cordis profile patch Harness
и перезапустите Harness. Блок использует официальный пакет
`@deepseek-ai/dsh-mcp-client`, транспорт `stdio`, namespace `mac-assistant` и
тайм-аут вызова 60 секунд. Этот режим предназначен только для разработки: обычное
подключение из интерфейса приложения записывает собственный idempotent patch
автоматически после подтверждения пользователя.

## Проверка границ

Полный набор XCTest проверяет allowlist и отказ `shell.execute`. Ручная
протокольная проверка посылает `initialize`, `tools/list` и запрещённый
`tools/call`; последний возвращает MCP-результат с `isError: true`, не исполняя
никакого внешнего процесса.
