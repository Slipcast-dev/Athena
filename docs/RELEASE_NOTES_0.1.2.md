# Athena 0.1.2 — архивные заметки об интерфейсе ИИ-чата

Подготовлено локально для обновления репозитория. Релиз ещё не опубликован.

- Приветствие и примеры вопросов, центральная колонка переписки.
- Компактные меню модели и истории, кнопка нового диалога.
- Многострочное поле ввода, отправка по ⌘ Return, остановка генерации.
- Вопросы справа, ответы слева, копирование ответа.
- Светлая и тёмная темы, переход к настройке провайдеров из пустого чата.
- Сохранены восстановление истории, потоковый ответ, отмена и повтор.

37 XCTest, debug/release-сборки и целостность распакованного приложения проверены.
Дизайн отрисован в 8 сочетаниях темы, размера и состояния.
Аудит выявил три существующих замечания в сетевом слое и замене Keychain-ключа;
подробности: `docs/AUDIT_0.1.2.md`.

Архивная локальная сборка 0.1.2: macOS 14+, Apple Silicon (arm64).
**Без Apple Developer ID и notarization Apple.** Gatekeeper может блокировать
установку. Сборка предназначена для осознанного тестирования.
В payload есть служебные AppleDouble-записи текущей среды macOS.
