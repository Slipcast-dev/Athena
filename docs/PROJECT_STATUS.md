## Что реализовано

- Нативный SwiftUI-интерфейс: обзор, диагностика, накопитель, ИИ-чат,
  ИИ-провайдеры, агенты и настройки темы.
- Локальные сведения о Mac, CPU, памяти, накопителе и диагностические
  рекомендации без `sudo`.
- Безопасный анализ выбранного каталога без удаления файлов и обхода ссылок.
- Профили совместимых ИИ-провайдеров с API-ключами только в Keychain.
- Локальный MCP-мост с четырьмя операциями чтения; произвольные shell-команды
  и файловые операции недоступны.
- Подключение и отключение только MCP-записи `mac-assistant` для Codex и
  DeepSeek Harness.
- Локальный установщик, CI GitHub Actions, правила вклада и документация
  публикации.
- Авторская лицензия: личное, образовательное и исследовательское
  некоммерческое использование разрешено, а исключительные права сохранены за
  `Slipcast-dev`.
- Предварительный GitHub Release с unsigned `.pkg` для технического
  тестирования; он не является доверенным установщиком для обычного
  распространения.
- Чат восстанавливает несколько диалогов и сохраняет их по ID; частичный ответ
  и повтор незавершённого запроса доступны после ошибки и перезапуска.
- Harness обрабатывается структурным YAML-парсером с точным сопоставлением ID.
- Получатель отчёта выбирается до согласия и показан вместе с API-адресом.
- Чат оформлен в духе ChatGPT: приветствие, центральная лента, многострочный
  редактор, меню модели и истории, копирование ответа и переход к провайдерам.

## Ограничения перед публичным выпуском

- Нужны сертификат Developer ID Application, hardened runtime и notarization.
- Нужна проверка installer на чистом Mac вне текущей среды разработки.
- Реальные облачные API не тестировались без пользовательских ключей.
- Статус интеграции Codex/Harness показывает собственную локальную запись;
  финальную проверку выполняют после перезапуска соответствующего клиента.

Подробности локальной упаковки: [RELEASE.md](RELEASE.md). Порядок первой
публикации: [GITHUB_PUBLICATION.md](GITHUB_PUBLICATION.md).

Актуальный аудит: [AUDIT_0.1.2.md](AUDIT_0.1.2.md). Найдены три существующих
замечания: повторная проверка HTTPS для streaming, неожиданное EOF потока SSE и
неатомарная замена Keychain-ключа. Новый дизайн проверен по отрисованным макетам;
интерактивная end-to-end проверка живого окна остаётся невыполненной.
