## Выполненные задачи

- Изучено единое техническое задание версии 1.0.
- Проверено исходное состояние рабочей папки: проектных файлов и зависимостей не было.
- Инициализирован Git-репозиторий с основной веткой `main`.
- Определён стартовый стек: Swift 5.9+, SwiftUI, macOS 14+, Swift Concurrency, XCTest и Swift Package Manager.
- Сформирован план поэтапной реализации с обязательными контрольными точками.
- Создан Swift Package с библиотекой `MacAssistantCore` и исполняемым приложением `MacAssistant`.
- Созданы типобезопасные модели для диагностики, накопителя, ИИ-провайдеров, чата и задач агента.
- Определены протоколы системной диагностики, анализа накопителя, ИИ-провайдера и Agent Bridge.
- Добавлен контейнер зависимостей с безопасной реализацией отсутствующих сервисов.
- Добавлены начальные XCTest-проверки контейнера и расчёта заполнения накопителя.
- Создан `NavigationSplitView` с семью русскоязычными разделами приложения.
- Каждый раздел вынесен в отдельный SwiftUI-экран, а повторяющиеся состояния готовности, загрузки и ошибки — в `FeatureScreen`.
- Добавлено отдельное системное окно настроек и ссылка на него из обзора настроек.
- Создан сценарий `script/build_and_run.sh`, формирующий локальный `.app`-пакет, и конфигурация кнопки запуска Codex.
- Реализован локальный сбор модели Mac, версии macOS, архитектуры и числа ядер CPU через системные API macOS.
- Реализован расчёт загрузки CPU по разнице двух последовательных Mach-снимков.
- Реализован сбор показателей RAM и системного накопителя без `sudo` и внешних процессов.
- Реализованы структурированный диагностический отчёт, документированные пороги и русскоязычные рекомендации.
- Дашборд обновляет локальные показатели с интервалом 5 секунд, пока его экран активен.
- Реализован выбор каталога через `NSOpenPanel`, безопасное сканирование и поиск файлов от 100 МБ.
- Символические ссылки и недоступные элементы не обходятся; сканирование можно отменить.
- Добавлены профили OpenAI, OpenRouter, DeepSeek, OpenAI-совместимых API и локального Ollama.
- API-ключи хранятся только в Keychain; профили в UserDefaults содержат только идентификатор записи Keychain.
- Добавлены HTTPS-валидация облачных адресов и ограничение HTTP только на loopback Ollama.
- Добавлены интерфейс чата, локальная история, выбор профиля и модели, копирование текста средствами SwiftUI и отмена активного запроса.
- Добавлены обезличивание диагностического отчёта, предварительный просмотр, явное согласие и передача только подтверждённого текста выбранному профилю.
- Изучены официальные материалы DeepSeek Harness и MCP-клиента; выбран рекомендованный для локальной программы транспорт `stdio`.
- Создан отдельный исполняемый MCP-процесс `MacAssistantMCP` с обработкой `initialize`, `tools/list` и `tools/call`.
- Реализован `LocalAgentBridge` со статическим списком четырёх операций только для чтения: сведения о Mac, показатели, локальная диагностика и сводка диска.
- Внешний агент не может передать shell-команду, путь, ключ, сетевой адрес или аргументы инструментов; неизвестные команды отклоняются.
- Экран «Агенты» отображает фактически доступный список операций и ограничения.
- Проведена стабилизация: полный набор XCTest, сборка Swift Package, протокольная
  проверка MCP и запуск локального `.app` прошли успешно.
- Исправлены два пограничных случая сканирования: отмена обрабатывается до
  перечисления пустого каталога, а каталог-символическая ссылка отклоняется.
- Подготовлены README, CHANGELOG, репозиторные инструкции `AGENTS.md` и
  инструкция релиза с явным разделением локальной и публичной поставки.
- Сценарий сборки дополнен командой `--package`: он собирает оптимизированный

  технической проверки.
- Добавлены три режима оформления: системный, светлый и тёмный; выбор сохраняется
  локально в настройках приложения.
- MCP-исполнитель теперь входит в `.app`; подготовлены безопасные команды
  регистрации в Codex и фрагмент конфигурации DeepSeek Harness.

## Известные риски и ограничения

- DeepSeek Harness находится в developer preview; перед обновлением протокола необходимо сверять совместимость с официальной документацией.
- Показатели нагрузки CPU необходимо рассчитывать по двум последовательным измерениям; единичный снимок не является корректной метрикой.
- Операции со сканированием файлов должны выполняться только для каталогов, явно выбранных пользователем, с соблюдением ограничений macOS TCC.
- Memory pressure отображается как недоступный, поскольку текущая реализация не использует источник, достаточный для его достоверной классификации.
- В MVP не создаются security-scoped bookmarks: приложение сканирует каталог только во время пользовательского выбора в текущем сеансе.
- Реальные облачные API не вызывались: в тестах не используются API-ключи и внешние сетевые подключения.
- Для OpenAI-compatible профилей чат использует SSE streaming с отменой; реальное подключение не проверялось без ключа.
- MCP-мост не устанавливается и не регистрируется в Harness автоматически: пользователь сам выбирает его конфигурацию. Инструкция и ссылки на первоисточники находятся в `docs/DEEPSEEK_HARNESS.md`.
- Облачные API и реальное подключение DeepSeek Harness не выполнялись: для них не
  предоставлены ключи или запущенный Harness. Локальные контрактные проверки MCP
  не заменяют внешнюю интеграционную проверку.
- Для внешнего распространения отсутствуют Developer ID Application, hardened
  runtime и notarization Apple. Локальный `dist/MacAssistant.app` не следует
  выдавать за подписанный публичный релиз.
- В sandbox-среде `pkgbuild` сопровождает payload служебными AppleDouble-файлами
  из системного provenance-атрибута. Они не содержат пользовательских данных и
  не влияют на код приложения, но перед внешним выпуском packaging следует
  повторно проверить на обычной macOS-системе с Developer ID.
- Фактическое подключение к установленным Codex и DeepSeek Harness зависит от их
  наличия на Mac. UI создаёт только локальную конфигурацию и не выполняет команды
  внешнего агента за пределами allowlist.
