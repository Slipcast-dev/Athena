Athena (ранее Mac Assistant) — нативный локальный помощник для macOS 14+ на SwiftUI. Он показывает состояние
Mac, формирует локальный диагностический отчёт, безопасно анализирует выбранный
каталог и подключает ИИ-провайдеров только по явной настройке пользователя.

> **Образ проекта:** Афина — ясность, защита и разумные решения. Athena
> не действует скрытно: опасные операции отсутствуют, а облачные данные
> отправляются только с явного согласия.

## Возможности

- Сведения о Mac, CPU, RAM и системном накопителе без `sudo`.
- Локальная диагностика с понятными рекомендациями.
- Поиск крупных файлов в каталоге, выбранном пользователем; файлы не удаляются.
- Профили OpenAI, OpenRouter, DeepSeek, OpenAI-compatible API и локального Ollama.
- Чат с локальной историей, потоковыми ответами совместимых API и отменой запроса.
- Восстановление нескольких диалогов, сохранение частичного ответа и повтор
  незавершённого запроса после ошибки или перезапуска.
- Новый интерфейс чата: приветствие, компактные меню модели и истории,
  многострочный редактор, копирование ответа. [Оформление и снимки](docs/CHAT_DESIGN.md).
- Обезличенный предварительный просмотр диагностического отчёта перед отправкой ИИ.
- Выбор получателя отчёта с названием профиля и адресом API; смена получателя
  требует нового согласия.
- Локальный MCP-мост с четырьмя безопасными командами чтения для Codex и
  DeepSeek Harness, с подключением и отключением из интерфейса.

## Требования

- macOS 14 или новее, Apple Silicon либо Intel Mac.
- Swift 5.9+ и инструменты командной строки Xcode для сборки из исходников.
- Интернет и API-ключ нужны только для облачного ИИ. Локальная диагностика и
  анализ накопителя работают офлайн.

## Быстрый запуск

```zsh
cd /Users/Aleksandr/Documents/Проекты/MacAssistant
swift test
./script/build_and_run.sh
```

Сценарий создаёт `dist/Athena.app` и запускает его. Для проверки запуска:

```zsh
./script/build_and_run.sh --verify
```

## Локальная релизная упаковка

```zsh
./script/build_and_run.sh --package
```

Команда собирает оптимизированный `.app`, проверяет `Info.plist` и ad-hoc
подпись. Такой пакет удобен для локальной проверки, но не предназначен для
публичного распространения: перед передачей другим пользователям нужны
Developer ID Application, hardened runtime и notarization Apple.

Чтобы подготовить стандартный локальный установщик `.pkg`:

```zsh
./script/build_and_run.sh --installer
```

Он создаст `dist/Athena-0.1.3-unsigned.pkg`. Установщик намеренно не
запускается автоматически: установка в `/Applications` должна быть подтверждена
пользователем macOS.

Тестовый установщик доступен в
[GitHub Release v0.1.1-unsigned](https://github.com/Slipcast-dev/MacAssistant/releases/tag/v0.1.1-unsigned).
Он не подписан Apple Developer ID и не нотарифицирован Apple.
Копия пакета и SHA-256 также находятся в [installers](installers/README.md).
Версия Athena 0.1.3 подготовлена локально; её публикация ещё не выполнялась.
[Повторный аудит](docs/AUDIT_0.1.3.md) подтверждает исправление трёх замечаний 0.1.2.
Подключение ИИ-провайдеров выполняется только в отдельном разделе «ИИ-провайдеры».

Bundle ID, Keychain service, имя MCP `mac-assistant` и технические SwiftPM-
модули сохранены для совместимости. После установки под новым именем старую
MCP-регистрацию с путём `MacAssistant.app` нужно отключить и подключить заново
из раздела «Агенты», затем перезапустить клиент.

## Codex, DeepSeek Harness и MCP

Мост запускается отдельным процессом:

```zsh
swift run MacAssistantMCP
```

Он использует `stdio`, не открывает сетевой порт и разрешает только чтение
системных сведений, метрик, диагностики и сводки диска. Подробности и настройка:
[docs/DEEPSEEK_HARNESS.md](docs/DEEPSEEK_HARNESS.md).

В разделе **Агенты** нажмите «Подключить» у нужного клиента. Приложение
зарегистрирует только собственный MCP-исполнитель `mac-assistant`; повторное
подключение не создаёт дубликаты. Кнопка «Отключить» удаляет только эту запись,
не изменяя другие MCP-серверы пользователя.

Для автоматического применения конфигурации DeepSeek Harness перезапустите
Harness после подключения. Дополнительные команды для сценариев разработки:

Для Codex:

```zsh
./script/configure_mcp.sh --codex
```

Для вывода фрагмента настройки DeepSeek Harness:

```zsh
./script/configure_mcp.sh --harness-config
```

## Тема

В окне **Настройки → Оформление** доступны режимы «Как в системе», «Светлая» и
«Тёмная». Выбор сохраняется локально и применяется к каждому окну приложения.

## Безопасность и данные

- API-ключи хранятся в Keychain, а не в репозитории или UserDefaults.
- Облачные адреса требуют HTTPS; HTTP допустим лишь для локального Ollama.
- Сканирование не обходит TCC, не следует символическим ссылкам и не изменяет файлы.
- Диагностические данные отправляются ИИ только после явного согласия.
- MCP-мост не исполняет shell-команды и не принимает пути к файлам.
