# Mac Assistant

Нативный локальный помощник для macOS 14+ на SwiftUI. Он показывает состояние
Mac, формирует локальный диагностический отчёт, безопасно анализирует выбранный
каталог и подключает ИИ-провайдеров только по явной настройке пользователя.

## Возможности

- Сведения о Mac, CPU, RAM и системном накопителе без `sudo`.
- Локальная диагностика с понятными рекомендациями.
- Поиск крупных файлов в каталоге, выбранном пользователем; файлы не удаляются.
- Профили OpenAI, OpenRouter, DeepSeek, OpenAI-compatible API и локального Ollama.
- Чат с локальной историей, потоковыми ответами совместимых API и отменой запроса.
- Обезличенный предварительный просмотр диагностического отчёта перед отправкой ИИ.
- Локальный MCP-мост с четырьмя безопасными командами чтения для DeepSeek Harness.

## Требования

- macOS 14 или новее, Apple Silicon либо Intel Mac.
- Swift 5.9+ и инструменты командной строки Xcode для сборки из исходников.
- Интернет и API-ключ нужны только для облачного ИИ. Локальная диагностика и
  анализ накопителя работают офлайн.

## Быстрый запуск

```zsh
cd /Users/Aleksandr/Documents/Проекты/MacAssistant
swift test
./script/build_and_run.sh
```

Сценарий создаёт `dist/MacAssistant.app` и запускает его. Для проверки запуска:

```zsh
./script/build_and_run.sh --verify
```

## Локальная релизная упаковка

```zsh
./script/build_and_run.sh --package
```

Команда собирает оптимизированный `.app`, проверяет `Info.plist` и ad-hoc
подпись. Такой пакет удобен для локальной проверки, но не предназначен для
публичного распространения: перед передачей другим пользователям нужны
Developer ID Application, hardened runtime и notarization Apple.

## DeepSeek Harness / MCP

Мост запускается отдельным процессом:

```zsh
swift run MacAssistantMCP
```

Он использует `stdio`, не открывает сетевой порт и разрешает только чтение
системных сведений, метрик, диагностики и сводки диска. Подробности и настройка:
[docs/DEEPSEEK_HARNESS.md](docs/DEEPSEEK_HARNESS.md).

## Безопасность и данные

- API-ключи хранятся в Keychain, а не в репозитории или UserDefaults.
- Облачные адреса требуют HTTPS; HTTP допустим лишь для локального Ollama.
- Сканирование не обходит TCC, не следует символическим ссылкам и не изменяет файлы.
- Диагностические данные отправляются ИИ только после явного согласия.
- MCP-мост не исполняет shell-команды и не принимает пути к файлам.
