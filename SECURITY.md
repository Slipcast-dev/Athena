# Безопасность Athena

## Сообщение об уязвимости

Не публикуйте API-ключи, токены, серийные номера, личные пути или подробные
диагностические отчёты в публичных issues. До появления защищённого канала
GitHub Security Advisories сообщайте о потенциальной уязвимости владельцу
репозитория приватно.

## Границы безопасности проекта

- API-ключи хранятся в Keychain и не должны попадать в Git.
- MCP-мост предоставляет только четыре операции чтения и не исполняет shell.
- Подключение и отключение изменяют только запись `mac-assistant`.
- Публикуемый unsigned installer предназначен только для осознанного тестирования;
  он не имеет подписи Apple Developer ID и notarization.
