# Вклад в Athena

Спасибо за интерес к проекту. Перед началом работы создайте отдельную ветку и
проверьте изменения на macOS 14+.

## Перед pull request

```zsh
swift test
swift build
python3 script/check_links.py
```

- Не добавляйте API-ключи, токены, диагностические отчёты или пользовательские пути.
- Сохраняйте русскоязычные комментарии для нетривиальной системной логики.
- Добавляйте XCTest для нового поведения и граничных случаев.
- Не расширяйте MCP-мост произвольными shell-командами или операциями изменения
  файлов без отдельной модели согласия и аудита.

## Pull request

Опишите цель, затронутые экраны и проверку. Если изменение касается хранения
данных, сети, ИИ-провайдеров или MCP, отдельно укажите его безопасность и способ
отмены операции.

Перед созданием pull request ознакомьтесь с [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md)
и заполните шаблон из `.github/PULL_REQUEST_TEMPLATE.md`.
