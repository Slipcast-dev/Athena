# Инструкции для разработки Mac Assistant

## Стек и архитектура

- Поддерживать macOS 14+, Swift 5.9+, SwiftUI и Swift Package Manager.
- Соблюдать MVVM и Service Layer; не помещать бизнес-логику в SwiftUI Views.
- Использовать `async`/`await`, actors и отмену для длительных задач.
- Передавать зависимости через протоколы и `AppContainer`.

## Безопасность

- Не хранить ключи, токены и пароли в коде, тестах, документации или логах.
- Хранить производственные API-ключи только в Keychain.
- Не запускать произвольный shell-код и не изменять пользовательские файлы без
  отдельного явно подтверждённого сценария.
- Не обходить TCC и не следовать символическим ссылкам при сканировании файлов.

## Качество

- Документировать нетривиальную логику и системные вызовы комментариями на русском.
- Добавлять XCTest для поведения, ошибок и граничных случаев.
- Перед фиксацией этапа выполнять `swift test`, `swift build`, проверку diff и
  проверку отсутствия секретов.
- Каждый блок завершать обновлением `docs/PROJECT_STATUS.md`,
  `docs/CHECKPOINTS.md`, коммитом и тегом.
