# Журнал изменений Athena

Формат основан на принципах Keep a Changelog. Установщики публикуются как
предварительные unsigned-релизы без Apple Developer ID и notarization.

## [0.1.3] — 2026-10-14 (подготовлено локально)

### Исправлено

- HTTPS проверяется перед чтением ключа и началом streaming-запроса.
- Неожиданный EOF SSE и повреждённые кадры становятся ошибкой; служебные
  role/usage-кадры поддерживаются, конец подтверждается DONE либо finish_reason.
- Keychain обновляется через SecItemUpdate; старый ключ не удаляется до записи.
- Иконка явно указана как `Athena.icns`, Dock получает тот же образ, сценарий
  сборки обновляет только запись приложения в LaunchServices.

### Изменено

- Приложение переименовано в Athena; внутренние ID и хранилища сохранены.
- Подключение провайдеров доступно только в разделе «ИИ-провайдеры»;
  кнопки подключения/настройки из чата удалены.
- Подготовлен `Athena-0.1.3-unsigned.pkg`; 44 XCTest проходят.

## [0.1.2] — 2026-10-14 (подготовлено локально)

### Изменено

- ИИ-чат оформлен в духе ChatGPT: центральная лента, вопрос справа, ответ слева,
  приветствие с примерами, компактные меню модели и истории, новый диалог.
- Многострочный редактор закреплён внизу; ⌘ Return отправляет сообщение,
  Return добавляет строку. При генерации доступна остановка.
- Добавлены копирование ответа, прямой переход к настройке провайдеров и
  автоматическая подстановка модели при смене профиля.
- Визуально проверены светлая/тёмная темы и компактный/широкий макеты;
  подготовлены установщик 0.1.2, контрольная сумма и отчёт аудита.

### Проверки и известные замечания

- 37 XCTest проходят. Аудит сетевого слоя и Keychain выявил три существующих
  замечания, описанных в `docs/AUDIT_0.1.2.md`; они не исправлены блоком дизайна.
- Версия ещё не опубликована в GitHub Releases.

## [0.1.1] — 2026-10-14

### Исправлено и улучшено

- История восстанавливается при открытии; обновление по ID сохраняет остальные
  диалоги. Повреждённый JSON не перезаписывается при сохранении.
- Переписка остаётся видимой при генерации и ошибке, индикатор расположен рядом
  с ответом. Частичный ответ сохраняется; повтор доступен и после перезапуска.
- Harness YAML разбирается по структуре через Yams 6.2.2: удаляется только
  точный ID `mcp-mac-assistant`, соседи сохраняются, повторное подключение
  идемпотентно. Повреждённый или неоднозначный YAML не изменяется.
- Перед отправкой отчёта можно выбрать провайдера и увидеть его API-адрес;
  смена получателя сбрасывает согласие.
- Установщик `0.1.1` включён в каталог `installers/` и предварительный GitHub
  Release; лицензии сторонних компонентов входят в bundle.

### Добавлено

- Авторская лицензия публичного некоммерческого использования: исключительные
  права сохранены за `Slipcast-dev`, а личное, образовательное и
  исследовательское использование разрешено.
- Авторская иконка приложения с цифровым образом Афины, подключённая к
  боковой панели раздела «Агенты» и к `.app` для Dock и Finder.
- Три режима темы: системный, светлый и тёмный.
- Локальный `.pkg`-установщик и сценарий безопасного подключения MCP-моста к
  Codex или DeepSeek Harness.
- Отключение Mac Assistant MCP из Codex и DeepSeek Harness без изменения других
  MCP-серверов пользователя.
- Предварительный GitHub Release `v0.1.0-unsigned` с тестовым `.pkg`-
  установщиком без подписи Apple Developer ID и без notarization.

### Изменено

- Навигационные иконки приведены к единому нативному стилю SF Symbols.

### Исправлено

- SwiftPM-ресурсы включаются в локальный `.app`, поэтому приложение не
  завершается при запуске и отображает свои ресурсы корректно.

## [0.1.0] — 2026-10-13

### Добавлено

- Нативное SwiftUI-приложение с разделами мониторинга, диагностики, накопителя,
  ИИ-чата, провайдеров, агентов и настроек.
- Локальные показатели CPU, памяти и накопителя, а также структурированный
  диагностический отчёт.
- Безопасный анализ выбранного каталога и поиск крупных файлов.
- Профили облачных и локального ИИ с хранением API-ключей в Keychain.
- Локальная история чата, SSE streaming и явное согласие на отправку
  обезличенного диагностического отчёта.
- Локальный MCP-мост DeepSeek Harness с allowlist команд только для чтения.
- Сценарий создания и проверки локального релизного `.app`.

### Исправлено

- Отмена сканирования пустого каталога обрабатывается до перечисления файлов.
- Каталог-символическая ссылка не принимается как корень сканирования.
